# Office Management System — Database Design

## 1. Purpose

This document defines the database architecture for the Office Management System.

The database uses PostgreSQL through Supabase.

The database must support:

- Multiple organizations
- Strong tenant isolation
- Employees
- HR
- Attendance
- Leave
- Holidays
- Clients
- Projects
- Procurement
- Vendors
- Assets
- Maintenance
- Training
- Internship
- Operations
- Finance
- Documents
- Notifications
- Audit logging
- Reporting
- Future AI functionality
